# ⚽ AI Football Player Analytics

An interactive Streamlit application that allows users to search for football matches, analyze player statistics, visualize performance metrics, and receive AI-generated coaching advice.

---

##  Features

- 🔍 Search football matches using SofaScore data
- 👤 Find specific player statistics
- 📊 Visualize performance metrics (passes, duels, shots, etc.)
- 🧠 Generate AI-powered coaching insights
- 📈 Interactive charts and data tables

---

##  Tech Stack

- Python
- Streamlit
- Selenium (for dynamic data fetching)
- SofaScore API (unofficial via scraping)
- OpenAI API (for AI coaching advice)
- Pandas & Matplotlib (data processing & visualization)

---

##  Demo

> Enter a match (e.g., *Morocco vs Senegal AFCON 2025*)  
> Select a player → Get stats + AI coaching advice
